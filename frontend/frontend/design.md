# Design System - Expense Tracker

## Design Direction

Clean iOS-inspired expense tracker.
The UI should feel calm, minimal, readable, and practical.

## Principles

- No heavy gradients
- No neon colors
- Use soft neutral background
- Use consistent spacing
- Use rounded cards
- Use subtle borders and soft shadows
- Accent color should be used only for important actions

## Colors

- Background: `#F5F5F7`
- Surface/Card: `#FFFFFF`
- Text Primary: `#111827`
- Text Secondary: `#6B7280`
- Border: `#E5E7EB`
- Accent: `#007AFF`
- Danger: `#FF3B30`
- Success: `#34C759`

## Layout

- Max width: 960px
- Page padding: 24px mobile, 32px desktop
- Card radius: 24px
- Card padding: 20px-24px
- Gap between sections: 24px

## Components

### Button

- Primary button uses accent color
- Danger button uses red
- Button radius should be rounded-full or rounded-2xl
- Avoid multiple competing button colors

### Card

- White background
- Subtle border
- Soft shadow
- Rounded-3xl

### Input

- Light background
- Border neutral
- Focus ring accent
- Clear label

## Typography

- Page title: large and bold
- Section title: medium and semibold
- Body text: normal
- Helper text: muted gray

## Avoid

- Heavy gradients
- Too many shadows
- Random colors
- Over-decorated cards
- Inconsistent border radius
